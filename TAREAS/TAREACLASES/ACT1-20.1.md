# 20.1

**¿Qué elementos de direccionamiento son necesarios para especificar un usuario de servicio de transporte (TS) destino?**

Se necesitan dos elementos de direccionamiento:

1) Dirección de red: Esto permite a los protocolos de las capas inferiores encaminar los paquetes a través de la red hasta llegar a la máquina fisica o nodo destino correcto, como una dirección IP.
2) TSAP (Transport Service Access Point): Como en un mismo host se pueden ejecutar múltiples aplicaciones al mismo tiempo, se necesita un identificador para saber a qué proceso específico dentro de la máquina se le deben entregar los datos.
