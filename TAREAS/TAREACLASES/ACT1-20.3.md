# 20.3

**Explique el uso de la multiplexación en el contexto de un protocolo de transporte.**

En la capa de transporte, la multiplexación se usa para optimizar los recursos de red y gestionar de forma eficiente la relación entre los procesos de software y la conexión física/lógica de red. Se clasifica en dos funciones principales:

1) Multiplexación hacia arriba: Consiste en montar múltiples conexiones de transporte para que viajen a través de una única conexión de red. Esto es fundamental cuando el host tiene asignada una sola dirección de red, como un único IP, y necesita que varias aplicaciones (por ejemplo: un navegador o un juego) comuniquen datos en simultáneo sin tener que pagar o establecer múltiples canales costosos a nivel de red.
2) Multiplexación hacias abajo: Ocurre cuando una única conexión de transporte se divide y se envía distribuyendo su tráfico a través de múltiples conexiones de red concurrentes. Se utiliza para incrementar el ancho de banda efectivo de esa aplicación (sumando la capacidad de las conexiones inferiores) o para garantizar una mayor fiabilidad y tolerancia a fallos.
