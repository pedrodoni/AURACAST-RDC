**Consigna:** ¿Qué proporciona UDP que no ofrezca IP?

**Respuesta:**

IP ofrece comunicación entre dispositivos (Host-to-Host), UDP actúa como una capa superior que añade comunicación entre aplicaciones (Process-to-Process) y una validación de datos más completa.

IP se encarga de encaminar y entregar bloques de datos entre computadores destino utilizando direcciones IP, no distingue qué aplicación específica dentro del computador debe recibir la información. UDP añade las siguientes funcionalidades clave sobre IP:

- **Multiplexación y direccionamiento de aplicaciones mediante puertos:** Añade campos para el puerto origen y el puerto destino, lo que permite dirigir los datos a un proceso o aplicación concreta dentro del computador receptor.

- **Detección de errores básica extremo a extremo:** Permite verificar la integridad de los datos entregados a nivel de transporte mediante mecanismos de suma de comprobación checksum.
