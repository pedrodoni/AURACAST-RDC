## Estructura

```
TP1/
├── RC - TP N1.pdf              # Consigna del TP N°1
├── Ejercicio_1/                # Ondas electromagnéticas
├── Ejercicio_2/                # Comunicación serie y codificación ASCII
├── Ejercicio_3/                # Transmisión y modulación de señales
└── Ejercicio_4/                # Armado de red simple en Packet Tracer

TP2/
├── RC - TP N2.pdf              # Consigna del TP N°2
├── Ejercicio_1/
├── Ejercicio_2/
├── Ejercicio_3/
├── Ejercicio_4/
└── Ejercicio_5/
```

Cada ejercicio incluye un archivo `*_Resuelto.md` con el desarrollo teórico/práctico y, cuando corresponde, una carpeta de imágenes con las capturas o diagramas de soporte.
