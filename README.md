## Estructura del repositorio

```
TP'S/
├── TP1/
│   ├── RC - TP N1.pdf              # Consigna del TP N°1
│   ├── Ejercicio_1/                # Ondas electromagnéticas
│   ├── Ejercicio_2/                # Comunicación serie y codificación ASCII
│   ├── Ejercicio_3/                # Transmisión y modulación de señales
│   └── Ejercicio_4/                # Armado de red simple en Packet Tracer
└── TAREAS/
    └── TAREA02/                    # Resoluciones grupales e individuales de la Tarea 2
```

Cada ejercicio incluye un archivo `*_Resuelto.md` con el desarrollo teórico/práctico y una carpeta de imágenes con las capturas o diagramas de soporte.

## Cómo navegar el repo

Usá el [Índice](#índice) de arriba: cada ítem apunta directo al archivo correspondiente dentro del repo. Las imágenes de cada ejercicio están referenciadas de forma relativa desde la misma carpeta.
